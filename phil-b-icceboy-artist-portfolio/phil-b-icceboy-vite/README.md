# Phil B Icceboy — Artist Portfolio

Premium responsive Vite + React artist portfolio.

## Run locally
1. Install Node.js LTS.
2. Extract the ZIP and open the project folder.
3. Run `npm install`.
4. Run `npm run dev`.

## Deploy to Vercel
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Music
The featured music section uses the artist bio's named tracks, Sampe and Nugi Baze. Buttons link to the official Audiomack artist profile because individual track URLs were not supplied. Replace these links with direct track URLs when available.
